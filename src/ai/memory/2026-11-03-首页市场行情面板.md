# 首页市场行情面板（2026-11-03）

- **对话时间**：2026-11-03 18:30 — 2026-11-03 18:57

## 需求背景

首页需要一个与博客业务无关的「市场行情」板块，一屏查看 A 股指数、美股指数、贵金属/原油、外汇（USD/CNH + 人民币中间价）的最新价、涨跌和交易状态。要求免费数据源、不暴露密钥、支持手动刷新与可选自动刷新、明暗主题正常、涨红跌绿，并且不新增路由和菜单。

方案来自用户确认过的 `src/ai/plan/market-plan.md`：后端代理 + Redis 缓存，前端只负责展示。

## 关键发现与分析

- **必须后端代理**：腾讯/新浪行情接口无 CORS，新浪还校验 `Referer`；浏览器直连不可行，且走后端可复用统一鉴权与缓存。
- **数据源与解析**：
  - 腾讯 `qt.gtimg.cn` 一次批量拉 A 股（`sh000300/sz399006/sh000688`）、美股（`usINX/usNDX`）、商品（`hf_XAU/hf_XAG/hf_OIL/hf_CL`）。A 股/美股按 `~` 分隔，价格/涨跌在 `[3]/[31]/[32]`，时间在 `[30]`；商品按 `,` 分隔，价格 `[0]`、涨跌幅 `[1]`、昨收 `[7]`、日期 `[12]`。
  - 新浪 `hq.sinajs.cn/list=fx_susdcnh`（GBK，需 `Referer: https://finance.sina.com.cn/`）取离岸人民币，最新价 `[8]`、涨跌幅 `[10]`、涨跌额 `[11]`、日期 `[17]`。
  - CFETS `chinamoney.com.cn/r/cms/www/chinamoney/data/fx/ccpr.json` 取 USD/CNY 中间价；按用户确认只展示最新发布值，不计算变动。
- **交易状态**：A 股 09:30–11:30/13:00–15:00（午休 `break`）；美股 09:30–16:00 美东（`zoneinfo` 处理夏令时）；商品/外汇周一 06:00 至周六 05:00（每日 05:00–06:00 收盘）。A 股/美股在开市时段内用行情自带日期与当地今天对比，不一致判为节假日。
- **降级策略**：Redis 正常缓存 30s，另存 10 分钟 stale 副本；上游全挂时回退 stale 并置 `stale: true`，单组失败只让该组价格为 `null`，不影响其他组。
- **前端交互细节**：首屏用骨架屏（行数对齐真实数据 3/2/4/2），刷新时用 `v-loading` 在数据区显示「更新中...」；自动刷新默认关闭、60s 一次、页面隐藏时跳过，开启后在头部展示呼吸绿点 + 「自动刷新中 · 60s/次」。
- **对齐问题**：条目行原用 `items-center`，会让「价格+涨跌幅」整体与名称居中；改为 `items-baseline` 后价格基线与名称基线对齐。

## 后续注意事项

- 腾讯/新浪为免费非官方接口，格式或服务端 IP 限制可能变化；解析集中在 `service/market.py`，必要时只改这里。
- 美股免费源通常延迟约 15 分钟，页面已明确提示，不可用于交易决策。
- 节假日判定是启发式：开市瞬间行情日期尚未刷新时可能短暂显示「休市」。
- 生产服务器必须能出网访问 `qt.gtimg.cn`、`hq.sinajs.cn`、`www.chinamoney.com.cn`。
- 接口不建议暴露给前台 `client` 端。
- `npm run build-check` 目前仍因仓库既有类型错误失败（`SysSettings`、`TagDialog`、`User/Activity`、`Home/index.vue` 未使用导入等），与本次功能无关。
- 已实际验证：真实行情数值、JWT 请求、30s 缓存命中、`force` 绕过、全量失败 stale 回退、单组失败隔离、`manage.py check` 通过。

## Token 使用建议

- 聚焦改动文件，避免整仓扫描；后端先用 `find`/`grep` 定位模块，再只读相关 `views/service/urls`。
- 行情类需求先 `curl` 上游确认字段下标，再写解析，能一次成形，减少反复试错。
- 验证时优先用 `manage.py shell` 直调 service，比登录拿 token 走完整链路更省 token。
