# 博客后台 Dashboard 功能分析（2026-08-12）

## 需求背景

用户想了解一个博客后台管理与前台客户端的首页分别应该包含哪些功能模块，希望能对照项目现状，明确已有什么、缺什么、优先补什么。

## 关键发现与分析

### 项目现状

- **技术栈**：Vue 3 + TypeScript + Vite + Pinia + Element Plus + ECharts 6 + UnoCSS
- **后端**：Python（代理 `/backapi` → `127.0.0.1:8000`），推测 Django/FastAPI
- **认证**：access token + refresh token + CSRF token 三重机制
- **主题**：支持明暗模式 + 5 种颜色主题（蓝/绿/红/紫/粉）
- **路径别名**：`@` → `src/`

### 仪表盘已有功能

| 模块 | 状态 |
|------|------|
| HomeOverview（欢迎语、进度、文章/草稿数） | ✅ 已完成 |
| ArticlePublishStat（文章发布趋势图） | ✅ 已完成 |
| RecentUserTask（近期任务时间线） | ✅ 已完成 |
| HotArticle（热门文章） | ✅ 已完成 |
| UserTaskScoreStat（个人评分趋势） | ✅ 已完成 |
| ActiveUser（活跃用户） | ⚠️ 空壳占位 |
| StatCard（统计卡片，代码已就绪） | ⚠️ 被注释掉未启用 |

### 缺失功能（按优先级）

1. **高优**：评论系统（API 层完全没有）、访问统计（PV/UV）、草稿箱独立管理
2. **中优**：Dashboard 快捷操作入口、内容健康度图表、任务到期提醒
3. **低优**：系统状态（存储、备份、运行天数）

### 独特点

项目内置了个人任务/目标管理系统（多维度评分：重要性、紧急度、成长值、幸福感、负面），这在一般博客后台中少见。

## 改动清单

本次为分析讨论，无实际代码改动。

## 后续注意事项

- StatCard 组件代码已写好，可取消注释直接启用，快速补齐 Dashboard 顶部概览卡片
- 若要补充评论功能，需同步开发后端 API（评论 CRUD、审核、垃圾标记）
- 前台客户端建议独立项目（Nuxt 3 或 Next.js），不跟后台共仓
- 前后台可共享部分 API，但权限模型不同（前台无需认证即可读文章）
- `/log` 指令不生效的问题：`.claude/commands/log.md` 缺少 YAML frontmatter，已修复
