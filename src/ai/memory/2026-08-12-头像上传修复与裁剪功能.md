# 头像上传修复与裁剪功能（2026-08-12）

## 需求背景

1. **头像不刷新**：上传完头像后，顶部导航栏（TopBar）的头像不会自动刷新
2. **头像裁剪**：希望上传头像时能从一张大图中截取部分区域（类似微信/知乎），而非直接使用整张图

## 关键发现与分析

### 问题1根因：本地状态与全局 Store 不同步

- 导航栏头像来自 Pinia store：`TopBar/UserInfo/index.vue` 通过 `storeToRefs(useUserInfoStore())` 读取 `userInfo.avatar`
- 个人资料页 `Profile/index.vue` 的 `getUserInfoHandler()` 调用 API 获取最新用户数据后，**只更新了本地 `baseUserInfo` ref**，未同步 Pinia store
- 因此上传头像保存成功后，页面本地的头像刷新了，但导航栏的 store 还持有旧值

### 类型不兼容问题

- `src/api/user/type.ts` 和 `src/store/user/type.ts` 都定义了 `UserInfoType`，但字段不同
- API 版本有 `email`、`talks`、`level`；Store 版本有 `id`、`loginTime`
- 因此不能整体赋值，只能按需更新共享字段

### 裁剪方案技术选型

- 选择 **cropperjs 1.6.2**（经典稳定版），内置 TypeScript 类型声明
- cropperjs 2.x 使用 Web Components 架构，API 完全不同，复杂度远超需求
- `@types/cropperjs` 是空 stub（cropperjs 自带类型），已卸载
- 包管理器：**npm**（非 pnpm）

## 后续注意事项

- 背景封面上传仍使用 `AppImageAutoUpload`，未改动（封面不需要裁剪）
- cropperjs 通过 CDN 引入 CSS（`import 'cropperjs/dist/cropper.css'`），需确保构建环境支持 CSS import
- 裁剪输出规格：200×200 JPEG、质量 0.9，如需调整尺寸可在 `AppAvatarCropper.vue` 中修改 `getCroppedCanvas` 参数
- Store 同步目前只更新了 `avatar` 和 `nickName`，如导航栏后续需要展示更多用户字段，需在 `getUserInfoHandler` 中补充同步
