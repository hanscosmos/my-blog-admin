# 个人事项与我的创作增加表格视图（2026-08-13）

## 需求背景

给两个个人中心页面增加表格视图，并支持按时间排序：

1. **个人事项（User/Task）**：在「面板 / 列表」基础上增加「表格」视图；支持按时间排序（最终确认为按**结束时间** `endTime`，后端跨分页排序）。
2. **我的创作（User/Article）**：参考文章管理-文章列表的表格，增加「表格」视图；新增搜索参数（标题、类别、文章状态、发布时间范围）；支持按**发布时间** `createTime` 排序。后续优化：搜索栏默认只展示标题和发布时间，其余收进「更多筛选」下拉。

## 关键发现与分析

### 后端分页与排序
- 两个列表接口都使用 `utils/tools.py` 的 `limit_queryset(params, sql)` 分页，默认排序依赖 model 的 `Meta.ordering`。
- 服务端排序需在 `limit_queryset` **之前**对 QuerySet 调 `.order_by()`（会覆盖 Meta.ordering）。
- 数据库为 MySQL，NULL 值在倒序时排在末尾 —— 个人事项中未结束任务（`endTime` 为空）会排到列表最后。

### 字段命名
- Django model 字段本身是驼峰命名（`endTime` / `createTime` / `startTime`），前端 camelCase 字段名可直接用于 `order_by` / `filter`，无需转 snake_case。

### 我的创作「发布时间」
- `createTime` 即发布时间：草稿转正文时，后端 `edit_article`（`modules/article/views/article.py`）会把 `createTime` 重置为 `datetime.now()`。

### 文章类别筛选
- 需连带子类：`ArticleCategory.objects.filter(father=params['category'])` 取子类 id，与所选 id 一起 `category__in` 过滤（与 `get_article_list` 逻辑一致）。

### 筛选栏折行
- 4 个筛选项全部平铺会折行，改为默认展示「标题 + 发布时间」，类别/状态收进 `el-popover` 的「更多筛选」下拉，内部提供「搜索 / 重置」按钮。

## 后续注意事项

- **后端需重启**：Django 代码改动后需重载/重启服务才会生效。
- **得分不可排序**：`score` 是后端计算属性（`value_score`），非库表字段，无法走 DB 排序；如需按得分排序需后端额外支持。
- **NULL 排序语义**：MySQL 下按 `endTime` 倒序，未结束事项排在末尾；如需「待办置顶」等特殊排序需另行处理。
- **排序为跨全部分页**：两页均采用后端排序（用户明确选择），前端 `sortable="custom"` 仅触发 `@sort-change`，不做客户端排序。
- **图标**：表格视图图标使用 icon-park 的 `table`（已确认存在于 `@icon-park/vue-next` 全量图标中）；筛选图标 `filter`、下拉箭头 `arrow-down`。
