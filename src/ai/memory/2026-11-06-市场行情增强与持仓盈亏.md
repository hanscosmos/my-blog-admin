# 市场行情增强与持仓盈亏（2026-11-06）

- 会话时间：2026-11-06 12:25 — 2026-11-06 13:33（UTC+8）

## 需求背景

在首页市场行情面板上分阶段增强：

1. 新增美股指数期货、亚太市场两个板块，并支持整块展开/收起。
2. 收起/刷新按钮改为图标。
3. 支持板块与板块内指标的拖拽排序（不跨板块），并新增醒目的自选行情板块。
4. 自选行情独占一行，条目排版不允许截断文字、不允许行高/换行不一致。
5. 根据自选资产的持仓市值与当日涨跌幅计算当日盈亏，并在自选板块头部汇总。
6. 将“国内金价（折算）”从贵金属组移到外汇组；贵金属组新增上海金，后按用户要求改为 Au9999。

## 关键发现与决策

### 行情数据源

- 美股指数期货：腾讯仅支持标普500期货，完整三项走新浪 `hf_NQ/hf_ES/hf_YM`；新浪期货不返回涨跌幅，后端按昨收计算。
- 亚太指数：腾讯无数据，走东方财富 `100.KS11/100.N225/100.TWII`，趋势接口同样可用。
- 上海金：东方财富 `118.SHAU` 可获取，但用户实际需要的品种是 Au9999，最终固定使用 `118.AU9999`，不再回退。
- 国内金价（折算）：仍由后端用伦敦金（美元/盎司）× USD/CNH ÷ 31.1035 计算，但展示位置从贵金属组移到外汇组。
- 外汇组包含逐日汇率报价，其中只有“国内金价（折算）”被视为可持有资产；USD/CNH、人民币中间价、美元指数不参与持仓。

### 拖拽与布局

- 使用 `@atlaskit/pragmatic-drag-and-drop`；拖拽数据区分 `type: 'group' | 'item'`，`canDrop` 同时校验 groupKey，避免跨板块移动。
- 采用在 `onDragEnter` 时交换顺序的方式，与项目既有 TabBar 拖拽行为一致。
- 自选板块固定置顶，不注册拖拽；自选条目可拖拽排序，顺序单独保存在 `favorites` 数组。
- 布局/自选持久化：`market-overview-layout`；折叠状态：`market-overview-collapsed`。

### 自选板块排版

- 自选板块 `:sm="24" :lg="24"` 独占整行；其余板块仍为两列/三列。
- 自选条目使用两列网格（窄屏单列），名称、符号、价格、涨跌幅均 `white-space: nowrap`，不使用省略号，避免文字截断。
- 每个条目固定展示一行盈亏（未设置时为 `--`），保证所有条目行高一致；价格/涨跌幅列 `flex-shrink: 0`，避免长名称挤压导致换行。
- 星标移动到名称右侧紧邻位置，顺序为：名称 → 星标 → 拖拽手柄 → 趋势图标。
- 拖拽图标保持 12px、悬停显示，不做放大（用户对比后认为原样式更好）。

### 持仓盈亏

- 用户明确所有资产均通过人民币持有，因此**不做汇率折算**：当日盈亏 = 人民币持仓市值 × 当日涨跌幅。
- 持仓设置弹窗按人民币录入；原先的 USD/CNH 折算、币种标签、未折算提示均已移除。
- 持仓以 `groupKey:itemKey` 为键存 localStorage：`market-portfolio-amounts`。
- 自选板块头部显示“今日盈亏”合计与设置图标；每个自选条目显示对应资产的当日盈亏。
- 纯汇率报价不允许设置持仓；国内金价（折算）虽在外汇组，但仍可设置持仓。
- 本金/持仓为静态市值，盈亏随每次行情刷新重新计算，属于估算值；休市时使用最近交易日涨跌幅。

### 自选迁移

- 板块调整会改变 `groupKey`（如 `commodity:xau_cny` → `fx:xau_cny`）。`useMarketLayout` 在行情加载后按 `itemKey` 自动迁移旧自选引用，避免收藏丢失。
- 贵金属新指标使用稳定 key `sge_gold`，即使后续更换数据源（上海金 → Au9999）自选也不会失效。

## 后续注意事项

- 持仓盈亏基于“当前人民币市值 × 最新涨跌幅”，不包含历史成本、累计收益、手续费；如后续需要累计盈亏，需增加成本价字段。
- 当前不做汇率折算；若后续直接持有美元/日元等资产，需要恢复币种配置与对应汇率数据。
- Au9999 暂未接入趋势弹窗（`TREND_KEYS`/`TREND_SECID_MAP` 未添加），点击条目不会打开趋势。
- 自选板块排版的 `nowrap` 依赖两列/单列宽度；若未来名称显著变长，需要重新评估列宽，不要直接加省略号。
- 行情缓存 30s；后端修改后需等待缓存过期或强制刷新。
- `vue-tsc` 仍存在项目原有错误：`HotArticle.vue` 缺少 `authorId`；与本次改动无关。
