# 个人中心心情功能（2026-08-14）

## 需求背景

在个人中心左侧用户信息面板（「编辑个人资料」下方）加一个「心情」功能：随时发内容表达当前心情，带历史记录，内嵌滚动展示。经确认拍板：

1. 心情形式 = 文本 + emoji 情绪（可选），后续追加支持发图片。
2. 历史记录展示 = 左侧窄面板（256px）内嵌滚动列表，显示最近 N 条。
3. 图片用「缩略图 + 点击看大图」解决窄面板空间不足。

## 关键发现与分析

- 后端是 Django（`modules/user`），标准套路：`models.py` → 迁移 → `views/*.py` → `urls.py`；用户 id 从 JWT 取（`get_user_id(request)`），前端不传。
- `UserProfile.talks` 是静态「一句话签名」，与「心情时间线」（多条带历史）语义不同，**独立建表，不混用**。
- 图片上传已有现成能力，无需新增接口：前端 `uploadFile(file, name, type)`（`src/utils/tool` 自动导入）→ `/sys/file/upload` → COS（`utils/upload.py`），`type='mood'` 传到 `mood/` 目录。
- 窄面板图片展示用 `el-image` 的 `preview-src-list` 实现缩略图 + 全屏预览。
- 发心情需同时记动态：复用 `add_user_activity(request, target_type, target_id, action, extra_data)`（`service/user.py`），新类型 `create_mood`；前端 Activity 组件需在 `activityMetaMap` + 非文章分支补该类型。
- 列表复用 `useSearch`（`isScroll=true` 追加模式）+ 手动「加载更多」；窄面板用 `max-h-60 overflow-y-auto` 约束高度，避开 `AppInfiniteList` 在 auto 高度容器里 IntersectionObserver 失效的问题。
- 约定：`src/views/...` 下的本地组件不自动导入，需显式 import（`src/components` 下才自动导入）。

## 后续注意事项

- **后端需迁移 + 重启**：执行 `.venv/bin/python manage.py migrate user` 落 `sys_user_mood` 表（仅 `user` app）；views/urls 改动后需重启 Django 服务。
- 图片走 COS 的 `mood/` 目录，单张大小受前端 `MAX_IMAGE_SIZE=10M` 限制；删除心情只删记录，不删 COS 文件。
- `vue-tsc` 全量仍有若干既有报错（Activity 的 `gotoView`/`deletedText` slot 类型、SysSettings、TaskTable、WorkBench 等），与本次改动无关。
