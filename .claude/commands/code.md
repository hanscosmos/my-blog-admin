编写代码时需要参考本文档之后再编写

## 参考信息
- 本项目是个人博客后台管理系统，是一个前端项目
- 项目的客户端源代码是与本项目同级目录的my-blog-client
- 项目的后端服务源代码是与本项目同级目录的my-blog-service


## 项目信息
- 项目使用vue3 + ts + vite进行开发
- 包管理器使用npm
- 项目配置了自动导入，vue, vue-router, element-plus相关组件，src/utils/tool下的方法无需额外导入
- 项目src/components下的组件可以自动导入


## 要求
- 如果有需要修改接口的地方，先询问我，然后根据我的意见作出修改
